# 7SealedStones 배포

최신 설치 파일 (v0.7.2): https://github.com/kgodkim/7sealedstones-builds/releases/tag/v0.7.2-install

- mac: `7SealedStones-mac-<버전>.dmg` (처음 열 때 '열지 않음' 창이 뜨면 시스템 설정 → 개인정보 보호 및 보안 → '그래도 열기')
- Windows: `7SealedStones-windows-install.ps1` (오른쪽 버튼 → PowerShell 에서 실행)

설치한 뒤로는 게임을 켤 때 이 저장소에서 스스로 업데이트한다.
