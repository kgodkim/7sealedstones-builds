# 7SealedStones 배포

최신 설치 파일 (v0.7.8): https://github.com/kgodkim/7sealedstones-builds/releases/tag/v0.7.8-install

- mac: `7SealedStones-mac-<버전>.dmg` (열어서 7SealedStones.app 을 Applications 바로가기로 끌어 놓고 응용 프로그램 폴더에서 연다. 처음 열 때 '열지 않음' 창이 뜨면 시스템 설정 → 개인정보 보호 및 보안 → '그래도 열기')
- Windows: `7SealedStones-windows-install.bat` 를 받아 두 번 누른다. 'Windows의 PC 보호' 창이 뜨면 추가 정보 → 실행. (bat 없이: `7SealedStones-windows-install.ps1` 를 받은 폴더의 PowerShell 에서 `Unblock-File -Path .\7SealedStones-windows-install.ps1` 뒤 `.\7SealedStones-windows-install.ps1`)

설치한 뒤로는 게임을 켤 때 이 저장소에서 스스로 업데이트한다.
